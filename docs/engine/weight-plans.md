# Weight plans and image ownership

Home: shared (host shared selection and cache identity; backend core runtime callbacks).

A storage descriptor never chooses numerical arithmetic. Each request names its admitted tensor, arithmetic, backend and incumbent kernel. The resolver checks eligibility before cost and retains the incumbent when no measured decision matches the exact compiler, device and workload. FAST requires explicit permission and a named contract. An image budget failure does not change arithmetic. Operand-exact test permission cannot become a model execution route.

`STRIX_WEIGHT_MEASURED_DECISIONS=0` is the rollback declaration for qualified replacements; family environment readers pass its resolved value through the shared helper. Strategy overrides use the typed request and fail if no eligible qualified registration exists. Missing throughput calibration produces an unavailable cost, never a fabricated prediction. Initial decision tables contain no replacements.

Measured tables use `wfmt.decisions@2` and require a source commit, compiler identity and flags, device, exact shape regime, versioned arithmetic, byte-receipt digest, byte equality and a measured speed result. Rows also require `build_identity`, `incumbent` and `replacement` as 64-hex content digests. The caller must verify the running executable/kernel-module digest and each registered implementation against the loaded artifacts before setting `ResolveRequest::build_identity` and `Candidate::implementation`; copying identities from receipts is forbidden. Missing identities decline replacements. The resolver matches these identities before translating a persistent implementation to a unique build-local dispatch ID. Version 1 numeric-ID tables are rejected. Registration order breaks ties. Import validates bounded metadata and rejects duplicate or unknown semantic keys. Receipts remain qualification inputs; importing metadata does not establish a device or full-model gate.

The cache reserves image and conversion workspace before work begins. Concurrent identical acquisitions share one conversion. Consumers wait for publication readiness; independent readers do not wait for each other's last-use events. Eviction requires all leases released and all recorded use complete. Content keys include source and sidecar digests, parameter metadata, tensor, slice, strides, shape, format, image, arithmetic, backend, architecture and ABI. A cache belongs to one backend/device. Failed last-use streams survive into retirement; the backend must fence/drain them or quarantine the allocation. Reservations remain charged through deferred reclamation, and workspace through readiness. Runtime callbacks may run under cache locks, must not re-enter the cache, and retirement must not throw. Their blocking latency needs qualification before concurrent serving adoption.

CPU allocation, copy and completion are immediate. Native runtime adapters provide vendor-local primitives with shared retirement mechanics. The native retirement service polls completion even when idle. After all contexts/caches stop submitting work, `shutdown_native_runtime()` joins the worker and drains pending events/streams; failed drains quarantine allocations and their charges. Shutdown is terminal for that backend runtime. Default-stream pageable uploads are explicitly completed before publishing readiness on a consumer stream. This serial staging path has no loading-performance qualification. Uncompiled adapters refuse explicitly. Intel's existing opaque queue has no event publication interface; an event-capable adapter must be supplied before cached images can be used there. No implicit host offload is performed.

Canonical family configuration objects can attach the same `FamilyPlans` result through `attach_weight_plans`. Configuration inspection before tensor admission reports pending plans. It does not invent a tensor index or change incumbent launches. The source migration supplies registrations and loaded maps at the existing shared configuration boundary.

Host checks cover eligibility, exact decision regimes, malformed imports, concurrent publication, budget and event failures, sidecar invalidation, deferred retirement, and configuration attachment through the GLM fixture; this does not establish executed CLI/serve tensor-dispatch parity. Existing numerical paths remain the comparison baseline.
